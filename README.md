# ევაკუატორი 24/7 — ლენდინგი

ერთგვერდიანი ლენდინგ ფეიჯი ევაკუატორის სერვისისთვის. მთლიანად ქართულად,
ზარზე ორიენტირებული — გვერდის ყველა CTA `tel:` ბმულზე მიდის.

**ტელეფონი:** 568 120 120

## სტეკი

- **Next.js 16** (App Router, Turbopack) + **React 19**
- **Tailwind CSS v4** — CSS-first კონფიგურაცია `app/globals.css`-ში
- **TypeScript**
- **lucide-react** — იკონები
- **FiraGO** — ძირითადი ფონტი, თვითმასპინძლობით (`app/fonts/`, ქართულ+ლათინურ
  დიაპაზონზე subset-ული woff2, 5 წონა ≈ 120KB)
- **Noto Sans Georgian** — მხოლოდ მთავრულისთვის (FiraGO-ს U+1C90–1CBF ბლოკი
  არ გააჩნია, ამიტომ TT-სათაურები და ღილაკები მასზე ეშვება)

## გაშვება

```bash
npm install
npm run dev     # http://localhost:4321
npm run build   # პროდაქშენ ბილდი
```

## სტრუქტურა

### ენის ავტომატური არჩევა

`proxy.ts` გვერდის ჩატვირთვამდე ამოწმებს ქვეყანას: GE → `/ka`, სხვა
ქვეყნები → `/en`, მათ შორის უკვე ლოკალიზებულ ბმულებზე. გადამისამართება
დროებითია (307), არ ქეშირდება და ინარჩუნებს მისამართის დანარჩენ ნაწილსა და პარამეტრებს.
`locale` და `locale-preference` cookie-ები აღარ გამოიყენება: რეკლამისა და
სხვა ახალ ბმულზე შემოსვლისას ძველი არჩევანი ქვეყანას ვერ გადაფარავს.
ენის ღილაკი კონკრეტულ ბმულზე ამატებს `?lang=ka|en|ru` პარამეტრს;
მხოლოდ ასეთი აშკარა არჩევანი გადაფარავს ქვეყანას. რეკლამის მისამართად
გამოიყენეთ `https://gadavikvanot.ge/ka` ან `/`, `lang` პარამეტრის გარეშე.
`gclid`, `gbraid`, `wbraid` და UTM პარამეტრები გადამისამართებისას ნარჩუნდება.

ჰოსტინგის სანდო პროქსიმ უნდა ჩაანაცვლოს `cf-ipcountry` / `x-vercel-ip-country`
ან კლიენტის `x-real-ip` / `x-forwarded-for` ჰედერები. ქვეყნის ჰედერის გარეშე
გამოიყენება არსებული ქართული IPv4 დიაპაზონების ცხრილი. IPv6-ისთვის საჭიროა
ქვეყნის ჰედერი; უცნობი ან ლოკალური IP-ისას ბმულის ენა ნარჩუნდება,
ხოლო `/` ინგლისურზე გადადის. ცხრილის სიზუსტე მის განახლებაზეა დამოკიდებული.

შემოწმება: `npm test`.

  globals.css       დიზაინ-ტოკენები, keyframes, ანიმაციების უტილიტები

  GeorgiaMap.tsx    საქართველოს რუკა (Natural Earth 50m გეომეტრია) + ქალაქები
